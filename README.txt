2026-11-03 当前版本：千秋电视 1.3.2（versionCode 15）。
直播播放恢复：播放期间每2秒监测；进度停止约12秒触发同频道重连。视频输出计数器可用时，也检测音频时钟继续但画面计数停滞18秒的情况。检测的是输出计数，不按画面颜色判断，静止场景不会被误判为卡死。
播放中断和直播EOF也进入重连，HLS的正数窗口时长不再被当成普通视频播完；显式直接点播及MP4等有限视频保留正常结束。
同一频道最多重连3次，间隔1/3/6秒；连续稳定播放60秒后恢复重试预算。手动换台、导入切换、退出时旧回调按播放代次失效；换台及退出会取消已排队重连。自动解码模式从第二次恢复开始可尝试软解；仅硬解/仅软解沿用用户选择。
停止、解绑和释放仍按后台stop、主线程detach、后台release顺序执行，避免UI等待原生stop。若底层停止本身长期不返回，后续播放器仍会等待其安全释放；本修复不强行并行复用同一Surface。
构建脚本先将应用class打包为JAR再交给D8，避免Windows批处理命令长度超限。
实机与边界：见 verification/recovery-1.3.2/report.txt。未发布或推送远端仓库。
