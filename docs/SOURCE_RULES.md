## 1. 三种数量与数据来源

## 2. 电脑筛选：本版初始集合的来源

六份列表共12278行，去重URL及请求头后10582条。按国内、港澳台及原有中文频道范围选出3478条进行预检，其中1621条进入完整检测。没有把全部海外地址逐条深测。完整检测有259条通过初筛；最终刷新及内容审查排除失效、身份冲突、占位等项目后，最终导出118条、97个条目。统计是本次快照，不能拿已测数量当当前有效数量。

HLS 使用两轮各4个不同的完整分片，最差下载速度余量≥1.5，每轮实际解码≥30帧并检查画面变化、播放清单进展。全部导出线路再次拉取完整分片并解码复查。抽样截图核对了部分台标，发现五个能解码却显示 NO SIGNAL 的地址并排除；其余节目身份、音轨语言和实时延迟未逐条人工核实。静态台标/演播画面与占位画面不能简单靠“帧相同”一概判错。

## 3. 盒子巡检：实际应用中的有效性标准

盒子只导入地址与频道，不导入电脑的成功标记、速度、测试时间或12小时缓存。首次符合条件的前台检查仍要本机检测。

1. HTTP/HTTPS 地址、有限重定向、超时、大小、响应完整性检查；拒绝 HTML、空分片、截断及206部分响应。不是 HTTP200 就算有效，也不发送小 Range 请求来计算速度。
2. HLS 两轮，每轮4个、合计8个不同分片标识；每段完整下载≤8MiB，单请求总上限12秒，读取超时2.5秒。没有足够新样本则等待并最终失败/暂停。选择主清单最高带宽变体；支持相对地址、AES-128与初始化段。字节范围HLS及不支持的加密方式不标合格。
3. 每个分片计算 `EXTINF媒体时长 / 从发起请求到完整下载的耗时`。八个样本中最小值必须≥1.5。比如6秒节目完整下载用4秒，余量为1.5倍；这衡量输送速度余量，不是端到端直播延迟。
4. 盒子通过独立 MediaExtractor/MediaCodec 对最终采样视频实际解码，至少30帧；不借用正在播放的 LibVLC 画面。直接TS/FLV以两轮各4个完整时间戳窗口检测，并校验解码。音频流、只成功连接却不能解码的视频均不算合格。
5. 盒子在线巡检目前**没有**电脑端的每轮运动帧/台标核对，也没有通用 NO SIGNAL 或内容识别。八个不同分片不等于已验证节目实时更新。已审查的五条占位地址通过明确 URL 排除表拦截，源站恢复后需在后续版本核对调整。其余能解码的错误节目或占位仍可能漏过。

## 4. 同台多源排序与失败处理

频道按规范名称归并，保持原有位置；每频道最多12条不同URL候选。顺序为当前地址、本版优先候选、缓存候选、在线补充；达到上限后的地址不参与本轮。候选是有界集合，不能称为“全网最快源”。同一URL归并，不复制成多条成绩。

对纳入的候选全部比较：先过合格门槛；在合格项里优先“最差速度余量”最大，再比较最慢分片耗时。不是优先第一个能连上的地址，也不是只看瞬间峰值。全部不合格时保留旧频道及旧URL供尝试，显示失败状态；没有获得合格标记。巡检更新不主动重启当前播放器、不切换频道或抢焦点，下次播放采用更新地址。

CCTV5 与5+、4K与4不混并；明确 `tvg-id` 的 CCTV4 欧洲/美洲版本保持区别。已核实的TVBS新闻地址按URL更名，不对整个TVBS名称做泛化。名称自动归并仍不是内容指纹识别，不能保证所有同名地址内容一致。

## 5. 12小时、断点和前后台边界

- `onResume` 是检查点：逐频道判断上次**完整比选完成时间**；12小时内成功或失败记录均跳过，满12小时才到期；系统时间回退视为过期。手动发起也遵循该有效期，不强制重测刚测过的频道。
- 每个已完成的分片样本、轮次和地址标识写入应用私有目录；同一源身份与12小时窗口内可续测。过期断点重来。未完成的频道不写完成时间，避免半测一次就被跳过12小时。
- 订阅抓取有独立12小时缓存；部分订阅失败时保留缓存与随包候选，抓取成功数仅代表列表取到，不代表其中地址都能播放。候选变更不会强制使12小时内已有频道成绩失效；下次到期再纳入。
- 仅在前台运行；自动检测遇到选台播放暂停。手动检测在播放时降为单路，否则最多3频道并行。每个工作线程自己取清单并立即取分片，避免在队列里放置即将过期的签名地址。
- 离开前台或用户停止会取消巡检；没有后台定时器、后台服务或自动唤醒。一次前台任务最长4小时，未完下次续测。后台写检查点和UI线程播放事件分别处理。
- 旧的小样本有效标记不沿用：当前本机健康记录需匹配schema2且满足8样本、30帧及1.5倍余量。电脑结果不参与这个状态。

## 6. 升级、隐私与限制

1.3.0对默认随包来源执行目录升级，保留193个旧频道名称/位置并合并别名，新增60个条目；用户自行导入的其他网络/本地列表不覆盖。默认目录升级会回到频道选择状态；不会自动播放。断点及有效记录继续按频道和源身份判断。失败不会退出应用或把用户抛回列表，上下可继续换台，Back主动返回。

发布内容不包含家庭局域网地址、ADB授权私钥、发行签名私钥、设备序列号、个人电脑路径或本机日志。播放URL本身可能带第三方公开列表提供的临时参数；不是本项目提供的会员凭据，源站过期后需要重新获取，勿当永久链接。应用可读取用户自定义局域网源，但本轮公开集合不含私人局域网源。检测数据保存在应用私有目录，没有上传检测日志的功能。

未做所有频道的长时间连续播放、全部设备硬解兼容性、节目内容及声音逐一核验、音画同步、直播端到端延迟或长期可用率测试。P2P并非本版依赖。短时输送合格和视频解码通过都不能保证以后绝不卡顿。
